# Agent Game

A stealth and tactics game: scan, plan, execute. 2D pixel art with mixed perspectives: top-down hubs and streets, and side-view building infiltration. Built with **Godot 4.7**.

- [Design Doc](Design%20Doc.md): the living design document
- [Brainstorm Report 2026-10-07](Brainstorm%20Report%202026-10-07.md): how the idea was split out from the megametroidvania

## Play the prototype
Open Godot, choose **Import**, pick `project.godot` in this folder, then press **F5**.

A/D or arrows move, Space/W jumps, hold Q to scan (slows time, shows guard armor), R restarts.
